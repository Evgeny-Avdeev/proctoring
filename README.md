# Самостоятельная работа

Веб-приложение для проведения самостоятельной работы в классе. Учитель открывает регистрацию, отправляет ссылку ученикам и запускает общий таймер. Ученики вводят имя и фамилию без аккаунта. Задание открывается у всех после старта. Ответы ученики выполняют на бумаге, приложение показывает задание и статусы.

## Текущая тестовая публикация

Оба интерфейса работают на [GitHub Pages](https://evgeny-avdeev.github.io/proctoring/).
Временное API работает в ChatGPT Sites. Оно хранит PDF и данные тестовых комнат. Пилот предназначен для взрослых с вымышленными именами и демонстрационными заданиями. Для создания комнаты нужен ключ учителя, который вводится отдельно.

В пилоте PDF загружается из защищённого API и отображается постранично через PDF.js. Модуль PDF.js загружается с jsDelivr. Тестовые комнаты закрываются для доступа через 48 часов после окончания работы или открытия регистрации для незапущенных работ. Просроченные комнаты и PDF удаляются при следующем успешном создании комнаты.

## Локальная проверка

Нужны Node.js 24+ и Poppler (`pdfinfo` и `pdftoppm` в PATH). Очистите `API_ORIGIN` в `docs/config.mjs` и запустите из каталога проекта:

```sh
node server/index.mjs
```

Откройте http://127.0.0.1:8080. Ключ учителя появится в терминале. Загрузите PDF, откройте ссылку ученика в другой вкладке, зарегистрируйтесь и нажмите «Начать работу» на панели учителя. Переключитесь с вкладки ученика и вернитесь. Статус обновится, а число переключений сохранится в таблице. Для проверки с разных устройств используйте HTTPS-вариант ниже.

## Размещение с собственным Node-сервером

1. Создайте отдельный репозиторий `proctoring` в GitHub и загрузите в него содержимое этого каталога.
2. В настройках **Settings → Pages** выберите **Deploy from a branch → main → /docs** и сохраните.
3. Запустите сервер на VPS или другом хостинге с Node.js и Poppler. Серверу нужен HTTPS, доступный с устройств учеников. Пример запуска за обратным прокси Caddy/Nginx:
   
   ```sh
   docker build -t classroom-proctoring .
   docker run -d --name classroom-proctoring --restart unless-stopped \
     --env-file .env -p 127.0.0.1:8080:8080 \
     -v proctoring-data:/data classroom-proctoring
   ```
   
   В локальном файле `.env` задайте случайный `TEACHER_KEY` длиной от 16 символов и `ALLOWED_ORIGINS=https://evgeny-avdeev.github.io` для Pages аккаунта Evgeny-Avdeev. Для другого аккаунта подставьте соответствующий origin без пути. Настройте обратный прокси на `127.0.0.1:8080`. Для Nginx установите `client_max_body_size 8m`.
4. Укажите HTTPS-адрес сервера и задайте `PDF_IN_BROWSER = false` в `docs/config.mjs`, зафиксируйте и запушьте изменение. Проверьте, что `/api/health` на сервере возвращает `{"ok":true}`, затем создайте тестовую работу на Pages. Ключ учителя вводится в форме. Храните его на сервере и передавайте учителям отдельно.

Сервер также сам отдаёт интерфейс. Его HTTPS-адрес можно использовать для проверки до настройки Pages, если `API_ORIGIN` пустой.

## Статусы и хранение

- Учитель получает свежую панель примерно раз в 2 секунды. Ученик отправляет статус при смене фокуса или видимости страницы и каждые 5 секунд, пока браузер позволяет. После 18 секунд без сигнала сервер показывает «Нет связи».
- Зелёный статус означает, что страница задания видима и в фокусе. Красный фиксирует потерю фокуса, переход страницы в фон или отсутствие связи. Переключение и обрыв связи могут иметь обычные технические причины. Эти сигналы сами по себе не показывают использование ИИ.
- Обычная веб-страница не блокирует выход в другие приложения, интернет или второе устройство. Удержание экрана зависит от поддержки Screen Wake Lock и настроек браузера. PDF отображается внутри страницы задания. Текст PDF представлен изображением, поэтому поиск по тексту и чтение его экранным диктором недоступны.
- Собственный Node-сервер хранит PDF, имена и сводку статусов в SQLite. Комнаты удаляются из рабочей базы примерно через 48 часов после окончания работы или открытия регистрации для незапущенных работ. У зарегистрированных учеников доступ к заданию есть только во время работы. Панель доступна по отдельному секрету, который сохраняется в браузере учителя. Передавайте ученикам ссылку из панели, она содержит только идентификатор комнаты.
